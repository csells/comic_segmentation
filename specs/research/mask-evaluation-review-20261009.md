# Specialist-mask runner review and independent fixtures

2026-10-09. Static review of `experiments/specialist_masks_v1/probe.py`, the broad research report and preprocessing results. No inference, paid calls, VM changes, dataset agreement or external contact was performed for this review. The twelve anthology pages remain development examples. User approval now permits the second isolated VM; earlier documents saying permission is pending are historical.

## Findings that affect the experiment

1. **ShadowB masks cannot independently rescue its own clipped boxes.** In pinned Ultralytics 8.4.43, `retina_masks=True` maps boxes to source coordinates and calls `process_mask_native`. That function resizes masks, crops them to the predicted bounding boxes, then thresholds them. A narrow tip outside a ShadowB box is therefore excluded by construction. The masks remain useful for shape and alternate proposals; do not interpret mask/box agreement as completeness evidence. [Predictor](https://github.com/ultralytics/ultralytics/blob/v8.4.43/ultralytics/models/yolo/segment/predict.py), [mask processing](https://github.com/ultralytics/ultralytics/blob/v8.4.43/ultralytics/utils/ops.py).

2. **Both supported APIs return source-sized binary masks.** RF-DETR 1.7.0 resolves to commit `e77de6698d69d09cd9abf2597e2e9a576169a119`. Its predictor resizes the RGB input to the configured square, then its postprocessor bilinearly resizes mask logits to the original height/width and thresholds at zero; it does not crop masks to boxes. Ultralytics' retina path also returns source-sized masks. Fail on unexpected dimensions instead of silently stretching an unknown, possibly letterboxed representation. Root reports this check and native-array preservation were added before inference. [RF-DETR predictor](https://github.com/roboflow/rf-detr/blob/e77de6698d69d09cd9abf2597e2e9a576169a119/src/rfdetr/detr.py), [postprocessor](https://github.com/roboflow/rf-detr/blob/e77de6698d69d09cd9abf2597e2e9a576169a119/src/rfdetr/models/postprocess.py).

3. **Call outputs postprocessed masks, not raw model logits.** Both APIs already threshold their masks. Preserving native arrays is sufficient for reproducing returned masks, but cannot support probability-threshold sweeps. Keep dtype, shape, checksum, threshold convention, empty-mask count and source dimensions. Validate aligned lengths, finite ordered boxes and class IDs; preserve rather than silently discard unexpected or empty output. Report mask support outside its box for Koharu separately from box geometry.

4. **The Koharu loader and recommended thresholds match the model author.** Class 3 is panel; class-specific thresholds are text .25, SFX .20, balloon .50, panel .50. Keep pre-class-filter detections or at least counts/scores so a missed low-confidence panel is distinguishable from no proposal. Its frame masks and balloon masks represent different entities; neither yields ownership or reading order automatically. [Pinned loader](https://huggingface.co/mayocream/koharu-layout-rfdetr-seg-2xl-1152/blob/aed55fdb8ca953c6bec33cf6ed6dd52a9b72bfa2/load_model.py), [card](https://huggingface.co/mayocream/koharu-layout-rfdetr-seg-2xl-1152).

5. **Memory and latency need precise labels.** `ru_maxrss` is a process-lifetime peak, not an individual page's allocation. First inference includes lazy initialization; it is not comparable to subsequent warm calls. Import/setup, model-load, inference, output encoding and total elapsed time should stay separate. Record package freeze, hardware, thread count and swap activity. RF-DETR upsamples all 160 selected masks before confidence filtering: a 1128×1648 float mask stack alone is about 1.19 GB, and very long webtoon inputs can multiply this. Do not run full-resolution long strips without a predeclared memory-safe analysis view and exact inverse mapping.

6. **The screen cannot select an end-to-end winner by panel count.** Inspect source, individual mask, rectangular crop, and scene/balloon ownership together. Record missed/merged/split scenes; required-content clipping; unrelated-scene inclusion; and unusably oversized windows. Mask IoU and score are diagnostics. Evaluate order separately, and retain whole-page fallbacks as failures of automatic segmentation coverage. Never supply reviewed mask corrections, manual seed points or evaluation labels to runtime.

## Concrete independent fixture candidates

Freeze complete series/artists outside policy tuning, with source URLs, access date, original byte hashes, image dimensions and attribution in a manifest. Every derivative must point to its original and transform. These candidates are independent of this anthology; **absence from foundation-model pretraining is unknown**. Three pages from one artist are not three independent books. A small screen should include at least three artists and positive/simple pages alongside hard layouts; a separate final test remains unopened until the policy is frozen.

Pepper & Carrot is still a relevant painterly-color candidate, but the current [license/about page](https://www.peppercarrot.com/en/about/index.html) also links the author's [October 8 statement about AI-generated derivatives](https://www.davidrevoy.com/article1178/license-update-ai-derivation-prohibited-on-all-my-art-lore-stories-and-comics). It focuses on generated art/stories and does not specifically adjudicate non-generative segmentation. Retain that distinction and current source terms instead of treating an old CC badge as the entire policy. No images were downloaded for this review and no author was contacted.

Bounded access checks also returned HTTP 200 for the [original xkcd 327 PNG](https://imgs.xkcd.com/comics/exploits_of_a_mom.png) (31,908 bytes reported) and [first Homem-Grilo WebP chunk](https://homemgrilo.com/wp-content/uploads/homemgrilo-hq013pg01_1.webp) (23,526 bytes reported). Only HTTP headers were retrieved, not image bodies. The LOC JPEG endpoint returned 403 too. The immediate accessible shortlist is therefore Homem-Grilo plus xkcd; the other rows are acquisition candidates, not ready fixtures.

This list does **not** fill genuine RTL manga, 4-koma, double-spread or independent borderless-book qualification. Use an explicitly permitted/user-owned separate manga book for those cells; translated or mirrored Western pages do not establish RTL manga performance. Do not reuse manga training-set books as held-out examples without checking the exact model split. No source here provides independent pixel/ownership gold labels: create review annotations before examining outputs and keep them outside runtime.

## Minimal next acceptance gate

Run the frozen automatic policy on the selected independent sources with unchanged prompts and thresholds. Review actual output crops, not only overlays. Stop on the first repeated structural class; if the policy changes, retire affected examples into development and allocate a fresh held-out group. Report per-book exact-page success, harmful false acceptance, fallback coverage, median/tail runtime and incremental/cold cost. A small perfect screen is an advancement gate, not a universal-perfection claim.
